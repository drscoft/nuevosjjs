drscoft.github.io

This repository was initialized from a Vite + React TypeScript starter. I added
an interactive icon set with animated effects (lightning, spark, storm) using
lucide-react and a global toggle to enable/disable effects.

To run locally:
	npm install
	npm run dev

Build:
	npm run build

Branch:
	feature/icons-effects - contains the changes for icons + interactivity
